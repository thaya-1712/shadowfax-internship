How this pipeline works

Documents are processed directly in the browser. Text and Markdown files are read directly and PDF files are extracted page-by-page using PDF.js.

The extracted text is divided into overlapping chunks. TF-IDF and cosine similarity are then used to find the most relevant chunks for the question.

The retrieved chunks are displayed so the user can inspect the information used for the answer.
